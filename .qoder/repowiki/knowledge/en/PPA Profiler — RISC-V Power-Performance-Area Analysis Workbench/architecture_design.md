The workspace is split into three cooperating layers: `backend/ppa` implements the FastAPI server (startup in `main.py` initializes SQLite via `db.init_db`, mounts CORS, registers `/api/*` endpoints for runs/scorecard/compare/design-space/power/timing/perf/hotspot/findings/ingest-status/rules and `/api/ai/*`), pluggable parsers under `ppa/parsers/` consume sample report files from `sample_runs/<run>/`, and `ppa/analysis.py` exposes view functions consumed by both the API routes and the AI agent. The `frontend/` React app calls these same `/api/*` paths via a typed client in `src/api.ts` against a shared `BASE = "/api"`. When a production build exists at `settings.frontend_dist`, the backend mounts it as static HTML at `/`; otherwise it falls back to a JSON health response, so the frontend is either served alongside the API or accessed separately during development. `sample_runs/` provides the canonical dataset that the backend's ingest pipeline parses and persists, driving every view.
