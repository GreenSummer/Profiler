Flat data directory organized as one subdirectory per configuration variant (e.g. baseline, rob96, rob128, issue6, l1d64, l2_1m, btac2k, nocg, leaky, rob192, rob256), each containing an identical set of five Synopsys/RTLA report files: primepower.rpt, rtla_area.rpt, rtla_qor.rpt, rtla_timing.rpt, specint.rpt. A single manifest.json at the root enumerates every run with its label, synthesized parameter set (rob_entries, lsq_entries, issue_width, l1d_kb, l1i_kb, l2_kb, btac_entries, clock_gating, vt_mix), PVT corner (tt_0p80v_25c), synthesis stage (rtla_predict), and execution order, serving as the canonical index that maps each folder to its design parameters. Reports are read-only artifacts consumed by downstream analysis scripts; there is no build or runtime code in this scope.
