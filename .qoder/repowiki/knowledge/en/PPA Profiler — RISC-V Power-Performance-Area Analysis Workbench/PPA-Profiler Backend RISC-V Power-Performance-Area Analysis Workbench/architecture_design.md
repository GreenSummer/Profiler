The `ppa/` package is the single Python application entry point (`main.py`, `cli.py`) that wires three cooperating sub-packages around a shared data layer. Parsers (`ppa/parsers/`) convert raw RTLA/PrimePower/SPECint text into typed dataclass reports consumed by the ingestion pipeline (`ppa/ingest.py`) which writes to the SQLite database (`ppa/db.py`). The core analysis engine (`ppa/analysis.py`, `ppa/rules.py`, `ppa/canonicalize.py`) reads those persisted reports and applies rules from `rules_pack.yaml` to produce diagnoses. The AI agent (`ppa/ai/`) sits on top of this same data layer, loading precomputed context packs and invoking the analysis engine through a typed tool interface so both the REST API and the LLM assistant share one source of truth. Cross-cutting concerns (FastAPI app lifecycle, logging, metrics, config) are centralized in `ppa/main.py`, `ppa/config.py`, and `ppa/metrics.py`, keeping parsers, the rule engine, and the AI layer free of framework coupling.
