The module is a single-page React app built with Vite. `index.html` mounts a `<div id="root">` and loads `src/main.tsx`, which creates a ReactDOM root, configures a TanStack Query client (30s stale time, single retry), and wraps the app in `QueryClientProvider`. `App.tsx` is the root component: it renders a top bar (run/baseline selectors, LLM status), a grouped sidebar (`NAV` table drives routing), a main content area that switches between view components via a `switch(view)` dispatcher, and an optional right-side `ChatPanel` for AI assistance. Global mutable state lives in `store.ts`, a Zustand store that persists `view`, selected `runId`, `baselineRunId`, and `compareIds` to the URL hash so the app is shareable; it also exposes an `aiContext()` helper that serializes current selection for AI prompts. Data access is centralized in `api.ts`, which defines typed GET/POST helpers over a `/api` base path and exports an `api` namespace mirroring backend endpoints (`/runs`, `/scorecard`, `/compare`, `/design-space`, `/area`, `/power`, `/timing`, `/perf`, `/hotspot`, `/findings`, `/ingest-status`, `/rules`, `/ai/*`). Shared TypeScript interfaces in `types.ts` describe all server payloads, and reusable chart/UI primitives live under `components/` while each analysis domain has its own page component under `views/`.
