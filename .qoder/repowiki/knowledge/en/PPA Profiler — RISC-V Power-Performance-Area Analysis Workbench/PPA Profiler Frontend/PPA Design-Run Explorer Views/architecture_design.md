Each file is a stateless React function component exported as a named view (AreaExplorer, Compare, DesignSpace, PowerExplorer, RunExplorer, Scorecard, TimingExplorer). Data fetching is centralized via @tanstack/react-query `useQuery` hooks that call the shared `../api` client with run-scoped query keys (e.g. `['area', runId]`, `['timing', runId]`, `['compare', ids.join(',')]`). Global UI state (selected run, baseline, compare set, current view) is read/written through the Zustand store via `useApp()` selectors (`runId`, `baselineRunId`, `compareIds`, `setRun`, `toggleCompare`, `setView`). Presentation is built from shared `../components/ui` primitives (`Card`, `Table`, `Delta`, `Kpi`, `Empty`, `fmt`, `shortModule`) and `../components/EChart` wrapping ECharts options. There is no internal sub-package structure — each view owns its own chart option objects and local `useState` filters, keeping views self-contained and dependent only on `api`, `store`, and shared UI/visualization components.
