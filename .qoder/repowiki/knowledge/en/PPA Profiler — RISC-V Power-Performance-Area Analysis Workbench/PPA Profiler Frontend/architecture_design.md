The app shell (`src/main.tsx`, `src/App.tsx`) bootstraps the React tree, wires up the global Zustand-like store in `src/store.ts`, and mounts the view components under `src/views/`. All views consume data through the centralized typed API client in `src/api.ts` and share TypeScript types from `src/types.ts`, while reusable chart and UI primitives live in `src/components/`. The Vite config (`vite.config.ts`) builds this single-page app against the backend's REST endpoints, so each view is an independent page/screen but they all depend on the same store + api contract for cross-view consistency.
